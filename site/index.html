    FAQ

    Questions,
    answered.

    Is it free?

    Yes. It's open source under the Apache-2.0 license, and the market data comes from public exchange feeds.

    Do I need API keys or exchange accounts?

    No. It only reads public market data, so there's nothing to sign up for and no keys to manage.

    Is the data really live?

    Yes. As long as the server is running it streams continuously. BTC, ETH and SOL start the moment your agent connects, and any other coin starts the first time you ask about it, then keeps streaming. History builds from that point: up to 8 hours of 1-minute footprint candles.

    How do I keep history running 24/7?

    When your agent app closes, the server it started closes too. To keep collecting around the clock, run it as a service with --http (or the Docker image) on any machine and point your agents at http://your-host:3333/mcp.

    Which coins are supported?

    124 crypto assets on perpetuals and spot, plus gold and silver perpetuals. Just say “BTC”, “eth”, or “SOL-PERP”; your agent can ask the server for the full list.

    Can it place trades?

    No. It's read-only market data for analysis. Nothing it returns is financial advice.

    An exchange shows “connecting”. What's wrong?

    Some exchanges block certain countries (Binance refuses US connections, for example). The other exchanges keep working, and the response tells your agent which venues are live. Corporate proxies work too: set HTTPS_PROXY.
